Use the distinction
Three checks.

        
A robots.txt decision should begin with the site's policy objective, not a copied blocklist or a vague “AI crawler” label.

      

      

        
1. Name the purpose
Decide separately whether you want search discovery, model-development collection, and user-triggered retrieval.

        
2. Preserve existing rules
Merge new directives into the site's current robots.txt. Do not overwrite sitemap, search, asset, or platform-specific rules.

        
3. Verify the public file
Fetch the final URL, confirm redirects and content type, and re-check provider documentation when behavior matters.
